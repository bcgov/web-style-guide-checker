# Security policy

## Supported versions

The current preview release identified in `preview-status.json` is supported. Versions below its minimum supported version should be updated before testing continues.

## Report a vulnerability

Do not report suspected vulnerabilities in a public issue or include sensitive page content, credentials, cookies or sign-in tokens in an issue.

Use GitHub private vulnerability reporting:

1. Open the repository's **Security** tab.
2. Select **Advisories**.
3. Select **Report a vulnerability**.
4. Describe the affected version, expected behaviour, observed behaviour and safe reproduction steps.

The maintainers will review the report privately and coordinate any disclosure after the issue has been assessed and addressed.
